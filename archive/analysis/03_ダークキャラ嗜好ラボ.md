# ダークキャラ嗜好ラボ

## 分離方針

ダークラボは `/dark-lab` からのみ入り、通常トップにはリンクを置かない。認証・quota・設定は共有するが、Entry、Identity/Work、Job、Ontology、Profile/Graph、Generationは `analysis_domain` で検証する。ダーク側の属性は `dark.*` だけであり、通常Ontologyへのfallbackやcross mappingは行わない。

既成（カスタム）の元キャラクターは通常分析器へ送らず、`DarkBaselineUnderstanding` で比較に必要な役割、主体性、道徳的約束、関係、責務、自己認識、既存の危うさだけを抽出する。この結果は `dark_baseline_snapshots` に保存し、プロフィール集計には入れない。対象状態だけを `DarkTransformationDelta` の保持・増幅・抑圧・反転・消失・追加・曖昧へ分類する。

## 解析段階

1. `dark_scope_assessment`: `in_scope | borderline | out_of_scope` を判定する。対象外だけユーザー確認で停止する。
2. `dark_baseline_understanding`: 既成（カスタム）の変化前比較を作る。
3. `dark_character_understanding`: 主体性、同意、認識、抵抗、自我連続性、責任、可逆性、時系列、変化差分を抽出する。
4. `dark_understanding_audit`: 通常時／闇状態、本人意思／外部支配、元から／後付け、役割／道徳性の混同を監査する。
5. `dark_preference_analysis`: 確認済み理解とユーザー入力から、対象状態・差分への嗜好だけを抽出する。
6. `dark_preference_audit`: 通常属性、根拠のない嗜好、元キャラクター自体への一般嗜好、不要な善化・悲劇化・贖罪を除く。

理解の修正・削除後は、現在有効な確認済みassertionから要約を再構築する。古いsummaryを嗜好解析へ再利用しない。ダーク差分は専用テーブルから読み直して嗜好解析へ渡す。

## 評価

`tests/fixtures/dark-analyzer-fixtures.ts` に、洗脳勇者、堕落英雄、操作された元味方、裏切者、純粋悪、ヴィラン主人公、アンチヒーロー、ダークヒーロー、モラリーグレーと7差分分類を交差した63件、および対象外対照7件を固定する。

実モデルの評価結果は次の形のJSONへ保存し、リリース前に `npm run eval:dark:gate -- <report.json>` を実行する。gateは、適格性macro F1 0.92、対象内recall 0.95、5抽出軸macro F1 0.87、嗜好precision 0.92、根拠参照精度1.0、重大混同・不要な善化0件、記録済みbaseline比+0.05を強制する。モデル名、prompt版、Ontology版、fixture版を評価reportへ記録し、実モデルを走らせていない結果を合格値として代入してはならない。
