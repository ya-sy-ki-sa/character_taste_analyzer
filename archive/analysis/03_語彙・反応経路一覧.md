# 語彙・反応経路一覧

## 1. この一覧の位置づけ

現行の `Ontology v1.0` は、LLM出力とプロフィール集計で表記を揃えるための統制語彙である。属性94件は「キャラクターに何があると理解したか」を分類し、反応経路44種類は「利用者がどのような意味で反応したか」を分類する。両者は別軸であり、たとえば `morality.villainous` に対して、人物好意、物語上の興味、逸脱への魅力、道徳的支持のいずれも取り得る。

この語彙は、現時点では心理尺度の設問や、母集団から標準化された性格特性ではない。属性definitionも「○○を表す統制属性」という短い実装定義であり、境界事例、除外条件、複数評定者による判定基準までは持たない。

確認元:

- [Ontology seed](../詳細設計/database/002_seed_ontology_v1.sql)
- [反応経路catalog](../../shared/response-channels.ts)

## 3. 反応経路44種類

反応経路は、同じ属性への反応を意味別に分けるための分類である。9種類の主要経路と、7カテゴリ35種類の詳細経路からなる。

### 3.1 主要経路 `popular`（9種類）

| key | 表示名 | 実装上の説明 |
|---|---|---|
| `person_liking` | 人物として好き | その人物自体に好感がある |
| `aesthetic_liking` | 見た目・デザインが好き | 外見、衣装、色、造形などに惹かれる |
| `voice_performance_liking` | 声・話し方・演技が好き | 声質、口調、話速、演技などに惹かれる |

## 4. 価値スタンスの補助語彙

嗜好assertionとは別に、善悪や逸脱を好意と切り分けるため、次の2軸を保存する。

| 軸 | 値 |
|---|---|
| 対象のorientation（7種類） | `evil` 邪悪、`immoral` 不道徳、`indifferent_to_good` 善に無関心、`transgressive` 規範逸脱、`self_defined` 自分の規範、`good` 善、`mixed` 混合 |
| 利用者stance（6種類） | `affirm` 肯定、`accept` 受容、`indifferent` 無関心、`ambivalent` 両価的、`reject` 拒否、`unspecified` 特定不能 |

これにより、「悪役が好き」を、自動的に「悪を支持する」へ変換しない。ただし現行の価値スタンス表示は生のassertion件数を並べる実装で、同一キャラクター・同一作品の重複補正はまだ行っていない。

## 5. 語彙設計上の注意

- 属性keyは検索・集計の分類子であり、利用者の人格評価や価値の高低ではない。
- `personality`、`morality`、`goodness`などには意味の近い項目があり、排他的分類ではない。
- `mixed` polarityは1つの独立した感情ではなく、現行集計では正・負双方へ半分ずつ寄与する。
- LLMは統制属性に当てはまらない候補を未マッピングのまま出せるが、未マッピング候補は現行プロフィール集計の対象外になる。
- 反応経路は複数選択でき、同じ属性でも経路ごとに別dimensionとして集計する。
- 学術的に利用するには、定義の明確化、内容妥当性調査、認知インタビュー、評定者間一致、因子構造・測定不変性などを別途検証する必要がある。
