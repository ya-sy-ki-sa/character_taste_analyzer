# 公開前評価セット

`dataset.example.jsonl` は評価器の動作確認用であり、人手評価200件の代用品ではありません。著作物本文を転記しない独自記述を用いて、別々の2名がラベル付けし、相違を裁定した200件以上のJSONLを運用側で作成してください。

各行には `source`、裁定済みの `gold.traitIds`、モデルの `prediction.assertions`、修復後の成否を含む `run`、二重ラベルの証跡 `review` を保存します。生成評価を行う行は `generation` も含めます。氏名やメールアドレスなど評価者の個人情報は入れず、組織内の仮名IDを使ってください。

```bash
npm run eval -- eval/production-200.jsonl
```

評価器は200件・全件二重ラベル、構造化出力99%以上、根拠参照100%、根拠なし属性2%未満、macro-F1 0.85以上、生成準拠99%以上を同時に満たすまで終了コード1を返します。モデル・プロンプト・属性体系の切替時は、同じ固定セットに現行版と候補版の予測を作り、修正率・根拠率・費用・待ち時間も比較してください。
