# 嗜好属性の実LLM評価例

プロンプトの抽象化・分割を確認するための人手による期待例です。固定応答を返す自動テストには使いません。実LLM評価を明示的に依頼された場合に、入力原文と出力を照合します。

期待属性は表現の完全一致ではなく、同じ意味・粒度であることを確認します。文字数ではなく、別のキャラクターでも比較できる評価対象の単位を確認します。固有の対象は引用・条件に保持し、属性名から除去します。否定、対象、条件、反応経路を広げず、dark版では一般的特徴を単独抽出しません。

| ケース | 版 | 好きな理由 | 期待する属性 | 注意点 |
| --- | --- | --- | --- | --- |
| standard-atoms | standard | 銀髪でチャイナ服を着た、好戦的で嗜虐的で傲慢な人物が好き。 | 銀髪／チャイナ服／好戦性／嗜虐性／傲慢さ | 原文の評価範囲を保持 |
| standard-proper-names | standard | 「作品A」の人物Aが振るう「道具A」は、巨大な剣である点が好き。 | 巨大な剣 | 「作品A」の人物Aが振るう「道具A」の造形。単独属性にしない：作品A／人物A／道具A |
| standard-inseparable | standard | 傲慢な人物が従属させられるところだけが好きで、傲慢さだけに惹かれるわけではない。 | 傲慢な人物の従属化 | 傲慢な人物が従属させられる場合に限る。単独属性にしない：傲慢さ／従属 |
| standard-negation | standard | 改心しないところが好き。 | 改心しない | 単独属性にしない：改心 |
| dark-control | dark | 洗脳・配下化という支配行動が好き。 | 精神支配／従属化 | 支配する側の行動 |
| dark-uniform | dark | 敵側のユニフォームと支配を示すデザインが好き。 | 敵対陣営への帰属を示す意匠／従属を示す意匠 | 単独属性にしない：制服 |
| dark-costume | dark | 黒いコスチュームと黒いバイザーの、黒色が悪役らしさを表すデザインが好き。 | 暗色を基調とした悪役的意匠 | 単独属性にしない：黒色／コスチューム／バイザー |
| dark-body | dark | 闇を象徴する暗い体の色が好き。 | 闇を象徴する身体表現 | 単独属性にしない：暗い体色 |
| dark-power | dark | 希望や友情を象徴していた力が支配や破壊のために使われる転用が好き。 | 肯定的な力の支配への転用／肯定的な力の破壊への転用 | 両方への好意を保持し、支配を破壊にまとめない。各転用に対応する条件を保持。単独属性にしない：友情／破壊 |
| dark-retained-traits | dark | 人物Aらしい口調・技・戦い方が残ったまま生じる通常との落差が好き。 | 本来の面影を残した変貌 | 人物Aの口調・技・戦い方が残る通常との落差。単独属性にしない：人物A／自我の保持 |
| dark-forced-opposition | dark | 洗脳によって敵陣営につくシチュエーションが好き。 | 意思を奪われた敵対化 | 洗脳による敵陣営への移行。単独属性にしない：自発的な敵対化 |
| dark-parallel | dark | 敵をいたぶる悪役としての好戦的・嗜虐的・傲慢な態度が好き。 | 悪役的な好戦性／嗜虐性／悪役的な傲慢さ | 敵をいたぶる悪役としての態度 |
| dark-immersion | dark | 現実から切り離された闇の支配展開への没入が好き。 | 支配的な展開 | 現実から切り離して鑑賞する。単独属性にしない：没入／道徳的支持 |
| dark-general-only | dark | 銀髪とチャイナ服が好き。悪役であることや支配・堕落とは関係なく、色と服の形だけに惹かれる。 | 候補なし | 単独属性にしない：銀髪／チャイナ服／悪役的な銀髪 |
| dark-general-with-context | dark | 銀髪とチャイナ服の形が好き。それとは別に、首輪が本人の意思を奪う支配の証として描かれるところに惹かれる。 | 従属を示す意匠 | 首輪が本人の意思を奪う支配の証として描かれる。単独属性にしない：銀髪／チャイナ服／首輪 |
| standard-condition | standard | 銀髪が好き。ただし冷淡な人物に限る。 | 銀髪 | 冷淡な人物に限るという条件を保持。冷淡さ単独への好意を作らない |
| standard-separate-contexts | standard | 戦闘中の傲慢さは好きだが、仲間に接するときの傲慢さは苦手。 | 傲慢さ（戦闘中：positive）／傲慢さ（仲間に接するとき：negative） | 同じ属性名で条件と極性を分ける。mixedや全条件の一括コピーで混ぜない |
| standard-independent-and-composite | standard | 傲慢さ自体が好き。それとは別に、傲慢な人物が従属させられる落差も好き。 | 傲慢さ／傲慢な人物の従属化 | 独立した好意が別々に明示されているため両方を保持。従属全般への好意は補わない |

## 反応・条件・主体の対照確認

ユーザーAの評価で観測した誤りを一般化した対照例です。表記や件数の完全一致ではなく、以下の意味の区別を確認します。実作品の固有名は使いません。

| 観点 | 入力と対照 | 確認する意味 |
| --- | --- | --- |
| 反応の否定 | 「大げさな口説き方が苦手。真似したいわけでもない」／「大げさな口説き方は好きだが、真似したいわけではない」／「真似したいわけではない」のみ | 前者は口説き方へのnegative、次はpositive、最後は対象への好悪未確定。どれも模倣という苦手属性や同一化願望を作らない。反応経路だけ不明ならnullで保持 |
| 同じ対象と異なる対象 | 「低身長を工夫で補う姿に自分を重ね、同じ姿に励まされる」／「工夫そのものが好き。低身長を工夫で補う姿には自分を重ねる」 | 前者は両経路で同じ対象名と必要な低身長の条件を保持。後者は工夫自体と低身長を補う工夫の評価範囲を区別。経路が異なることだけで重複と判定しない |
| 経験の主体 | 「人物が失敗しても挑み続ける姿を見て、自分も部活の練習を再開した」／「人物が失敗しても部活の練習を再開する姿が好き」 | 前者の練習再開はユーザー、後者は人物。前者で人物が練習を再開した事実を作らない |
| 省略された相手 | 「笑顔で来てくれると安心する」／「作中で、人物Aが人物Bのもとへ笑顔で来てくれると安心する」 | 前者の訪問先をユーザーと決めない。後者は人物Bであり、安心するユーザーと混同しない |

候補名の長さや反応経路のnullだけを不合格にしません。関係・落差に必要な意味、反応経路ごとの評価範囲、引用と文脈の保持を優先します。この例の追加は実モデルでの改善実証ではありません。

## 規範的な価値態度と反応経路の判定境界

`preference/v3.9.0` の期待例です。同じ候補を抽出と監査で比較し、経路の検出と、人物・ユーザーの主体の保持を別々に評価します。自己類似はユーザーによる主観的な照合として扱い、人物に同じ心理があるという事実認定は要求しません。

| 観点 | 入力と対照 | 確認する意味 |
| --- | --- | --- |
| 好意と規範 | 「人を助けるところが好き」／「人を助けるのは正しい行いだと思う」 | 前者だけでaffirm/goodを追加しない。後者は規範的な肯定として保持 |
| 悪への反応 | 「残酷な戦い方がかっこいい」／「この場面での残酷な報復は正当だと思う」 | 前者は嗜好であり道徳的支持も不支持も補わない。後者の支持は当該場面に限定 |
| 憧れと願望 | 「恐怖に負けず助ける姿に憧れる」／「自分も怖くても助けられるようになりたい」 | 前者はadmirationで、願望を補わない。後者は特定行動へのwishful_identificationであり、人物全体になりたいという宣言は不要 |
| 主観的な自己照合 | 「再挑戦する姿が好き。自分も失敗が多いから励まされる」／「再挑戦する姿が好き。自分も部活をしているが似ているとは思わない」 | 前者は失敗・再挑戦に限定した自己照合と励ましの根拠を検討する。後者は自己類似を追加しない。どちらもユーザーの部活・経験・心理を人物の経歴に移さない |
| 外見・行動・作劇 | 「衣装の配色がかっこいい」／「困難に立ち向かう生き方がかっこいい」／「台詞の反復で成長を描く脚本が巧い」 | 外見はaesthetic_liking、生き方はadmiration、脚本はcharacter_craft_appreciation。同じ評価語だけで経路を揃えない |
| 反応だけ未確定 | 「不器用でも約束を守るところが好き。安心なのか憧れなのかは分からない」 | 対象・好意・条件を保持し、経路はnullへ改訂。改訂後の命題のscopeと根拠の支持を再判定。経路不明だけで好意を除外しない |

これらは期待する仕様であり、新版での実測結果ではありません。候補の追加数だけでは採点せず、過剰推論・取りこぼし・主体の取り違えを個別に記録します。

## 記号媒体と文脈上の意味の対照確認

処理仕様化と専門概念の導入に対する人手の期待例です。人物理解の情報と好みの根拠を分離し、理論から象徴的意味を補わないことを確認します。

| 観点 | 入力と対照 | 確認する意味 |
| --- | --- | --- |
| 形そのもの | 通常版「首輪の丸い形が好き。従属の意味には惹かれない」 | 丸い形の首輪への好意を保持。従属への好意を追加しない。「惹かれない」だけから嫌悪を確定しない |
| 意味との結びつき | dark版「首輪が意思を奪われた証として描かれるところが好き」 | 従属を示す意匠。首輪一般への好意へ拡張しない |
| 作品内の意味と好みの分離 | 確認済み人物理解「黒い制服は敵陣営への帰属を示す」。好み「黒い色そのものが好きで、帰属の意味には惹かれない」 | 通常版は黒色への好意。dark版は帰属への好意を生成しない。人物理解に象徴的意味があるだけでは好みの根拠にならない |
| 同じ媒体・異なる意味 | dark版「人物Aの制服が敵陣営への帰属を示す点と、人物Bの制服が意思を奪われた従属を示す点が好き」 | 帰属を示す意匠と従属を示す意匠を分け、主体を保持。同じ制服だからと統合しない |
| 異なる媒体・同じ意味 | dark版「制服とバイザーが同じ敵陣営への帰属を示す、その統一された表現が好き」 | 一つの帰属を示す意匠として扱い、媒体の数だけ属性を増やさない |
| 仮説と抽出の境界 | 確認済み人物理解に従属を示す意匠があるが、ユーザーはその意匠への好悪を未表明 | 抽出では好意を確定しない。仮説では許可済み属性・反応に対応する場合のみ、未確認の選択肢として提案可能 |

これらは新しい期待例であり、実モデルでの評価結果ではありません。用語の出現や候補件数だけで合格とせず、原文との意味の対応を評価します。
