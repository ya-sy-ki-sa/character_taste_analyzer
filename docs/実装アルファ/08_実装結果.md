# P0〜P2 実装結果

更新日: 2026-08-30

## 実装境界

- `004_alpha_hardening.sql`をexpand migrationとして追加し、既存根拠432件を`legacy_unverified`へ移行した。
- `005_customized_base_character_name.sql`で既成（カスタム）の元キャラクター名と表示名を分離し、既存16 Entry・37 revisionは従来のキャラクター名で補完した。
- source-of-truth更新、quota予約、job、outboxをD1 batchで確定し、lease付きdispatcherと世代フェンスでat-least-once実行を制御する。
- profile/graphは利用者単位のdesired/built generationを持ち、両成果物が完成するまで旧currentを返さない。
- 入力フィールド、外部出典、モデル知識を区別し、quoteのoffset/hashはサーバーで計算する。不一致根拠は`invalid`として隔離する。
- generationは決定的検査、独立LLM意味検査、1回だけの修復、再検査を行い、再違反候補を公開しない。
- account exportはprivate R2 objectとして非同期作成し、認証済みendpointから24時間だけ提供する。
- `/api/v1`はsnapshot/run中心review、identity candidates、非同期export、live/readyへ更新し、旧APIを削除した。
- React routeとgraphをlazy loadし、graph代替表、Modal focus管理、profile freshness表示を追加した。
- `npm run verify`へformat、lint、type、coverage、DDL/Schema/OpenAPI/prompt、build、secret、bundle、hermetic E2Eを集約した。

## 契約と運用

- 目標契約: `docs/詳細設計/api/openapi.yaml`
- 実装契約: `docs/詳細設計/api/openapi.as-built.json`
- migration: 5件、66 table、初期属性94件
- coverage gate: 全体80%/branch 75%。状態policy、quota、provenance verifier、generation validatorはbranch 90%
- E2E: Chromium全導線、Firefox/WebKit/mobile主要smoke。毎回、一時D1とReplay LLM/Fake embeddingを新規起動する。
- 現行unit: 15ファイル・79テスト。coverageはstatement 97.17%、branch 92.13%。
- ローカルE2EはChromium全7件、Firefox smoke、mobile smokeの計9件成功。WebKitはホスト共有ライブラリ不足とsudo不可によりローカル起動できず、`--with-deps`を使うGitHub Actions gateで実行する。
- staging/productionのD1、R2、Workflow、Vectorizeの実resource ID・bucketはdeploy前に`wrangler.jsonc`のplaceholderを置換する。remote resource作成・deployは今回実施していない。

## ローカルデータ

ローカルD1はtimestamp付きSQLへbackupし、別SQLiteへのrestoreを確認してからmigrationを適用した。全22 EntryをOpenAI `gpt-5.6-luna`でconcurrency 1再分析し、22件とも理解確認待ち、失敗Entry 0件、自動confirm 0件で終了した。詳細値は[移行レポート](07_ローカル移行結果.json)に記録している。

旧寄与は再分析開始時に除外した。対象19 ownerのprofile freshnessはすべて`queued`かつdesired/built不一致であり、利用者が理解と嗜好を再確認するまでprofileへ戻らない。

## 既知の受容事項と対象外

- `AUTH-01`: 利用者指定により仕様として受容。キー表示、dismiss、rotation、復旧不能時の挙動は変更していない。
- P3の`PRIV-02`、`QUAL-01`、`QUAL-02`、`GOV-01`: 今回の対象外。
- remote Cloudflare resource作成、deploy、負荷試験、法務判断: 今回のローカル実装・受入範囲外。
