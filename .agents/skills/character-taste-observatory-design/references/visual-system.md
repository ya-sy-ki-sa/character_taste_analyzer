# 観測装置ビジュアルシステム

## 1. 世界観の定義

キャラ嗜好ラボのUIは「キャラクターへの好きという反応を、表情・信念・関係性・葛藤などの軸から観測し、座標と記録へ変換する私設研究装置」である。

視覚的な参照先は、宇宙船の操縦席ではなく、暗室の天体望遠鏡、真鍮の測定器、光学レンズ、紙の星図、校正用の目盛り。未来的な万能端末ではなく、一つの用途へ作り込まれた道具として扱う。

通常版は、完全な円、閉じた結線、均等な目盛り、整備された金属によって「正常に観測できる」安心を示す。赤い信号と黄白の光は、警戒ではなく現在の操作や測定点を知らせる、制御された局所光として使う。欠損、偏心、腐食、説明不能な軌道はdark版へ予約する。

## 2. 通常版の基本トークン

コンポーネントは素材名ではなく、次の共通の役割名を参照する。dark版も同じ変数を上書きするため、テーマ切替でコンポーネントCSSを分岐させない。既存のコントラスト要件や状態色と衝突する場合は、役割を保ったまま明度を調整する。

```css
:root {
  color-scheme: dark;
  --ctl-void: #06080a;       /* ページ最背面 */
  --ctl-chassis: #101315;    /* 筐体 */
  --ctl-panel: #15191b;      /* 操作盤・フォーム面 */
  --ctl-lens: #080d0e;       /* レンズ内部 */
  --ctl-text-primary: #eee6d6; /* 主見出し・主要本文の生成り */
  --ctl-text-muted: #a6adaf;   /* 補助本文。これより暗くしすぎない */
  --ctl-control-edge: #667176; /* 非活性部・入力枠 */
  --ctl-structure: #c49a5a;    /* 真鍮の目盛り・境界・校正情報 */
  --ctl-action: #9f382b;       /* Primary面。主要文字と5.5:1 */
  --ctl-signal: #f15d48;       /* 現在位置・選択・警告の小面積信号 */
  --ctl-local-light: #ffd0a5;  /* 黄白の信号灯・焦点光 */
  --ctl-line: rgb(238 230 214 / 15%);
  --ctl-metal-line: rgb(196 154 90 / 32%);
  --ctl-shadow: rgb(0 0 0 / 68%);
}
```

### 使用比率と意味

- `void`、`chassis`、`panel`、`lens` が画面の大部分を占める。近い黒を面ごとに使い分け、真っ黒一色に潰さない。
- `text-primary` は最重要情報、`text-muted` は説明、`control-edge` は非活性・補助境界に使う。
- `structure` は精密さを示す真鍮色。目盛り、リング、区切り、装置IDへ限定する。
- `action` はPrimaryの面、`signal` は現在位置、選択、警告、ボタン境界など「今反応すべきもの」に使う。赤い大面積はPrimary一つに限定する。
- `local-light` は信号灯やレンズ反射に限定する。黄白のグローを本文や広い背景へ敷かない。
- 通常サイズの文字は背景とのコントラスト比4.5:1以上、大きな文字と重要な境界は3:1以上を維持する。

## 3. タイポグラフィ

3つの役割を混ぜない。

```css
--ctl-font-display: "Yu Mincho", "Hiragino Mincho ProN", "Noto Serif JP", serif;
--ctl-font-body: "Hiragino Kaku Gothic ProN", "Yu Gothic UI", "Noto Sans JP", sans-serif;
--ctl-font-utility: "SFMono-Regular", Consolas, "Liberation Mono", monospace;
```

- **Display:** 製品名と短い主見出し。明朝の縦横差で光学器械の品格を出す。太さを上げすぎず、字間 `0.04em–0.09em`。
- **Body:** 説明、フォーム、ナビゲーション。日本語ゴシック、行間 `1.65–1.9`。本文は原則14px未満にしない。
- **Utility:** 装置ID、角度、座標、短い英字ラベル。10–12px相当、字間 `0.08em–0.14em`。長文や主要操作には使わない。
- 日本語を主、英字を補助にする。英字だけで機能を説明しない。
- 外部フォントは既存プロジェクトが既に利用している場合だけ使う。フォント読込失敗で階層が崩れないフォールバックを必ず持つ。

## 4. 空間と筐体

基本スペースは `4, 8, 12, 16, 24, 32, 48, 64px`。主要操作の高さは48px以上、タップ領域は44px以上とする。

デスクトップの代表構成:

```text
┌──────────────────────────────────────────────────────────────┐
│ ブランド／装置名       DEVICE ID                 準備状態    │ 64–72
├─────────────────┬──────────────────────────────┬─────────────┤
│ 説明・操作盤     │                              │ 校正レール  │
│                 │       大型観測スコープ        │ 48–64       │
│ 主見出し         │      （画面の記憶点）         │             │
│ 主要操作         │                              │             │
├─────────────────┴──────────────────────────────┴─────────────┤
│ プライバシー／装置情報                                      │ 44–54
└──────────────────────────────────────────────────────────────┘
```

- ページ外周に一つの筐体を置き、その内側を1pxの線で区切る。各領域を浮いたカードにしない。
- 角は原則0–2px。円形はレンズ、ダイヤル、信号灯など、意味が円形である部品だけに使う。
- 奥行きは面の明度差、内側シャドウ、同心円リング、細い境界で作る。ぼかした大きな影を何層も重ねない。
- 素材感は `repeating-linear-gradient` や低不透明度の放射光でわずかに足す。テクスチャの不透明度は概ね0.01–0.04に抑える。
- 非対称を許容する。説明パネルは狭く、スコープは大きく、校正レールは細くして機能差を形にする。

## 5. 署名要素: 嗜好観測スコープ

スコープは飾りではなく、対象画面のデータまたは概念を示す。

- 外周: 完全な暗い金属リング、均等な真鍮の目盛り、0/90/180/270度の最小限の表記。
- レンズ: `--ctl-lens` の面に薄い同心円、照準線、星点。中央は嗜好または現在の観測対象。
- 観測軸: 基本は「表情」「信念」「関係性」「葛藤」。画面内容に応じて、実データに存在する軸へ置換してよい。
- 結線: 点を意味のある閉じた線で結ぶ。SVGを使い、装飾のためだけのランダム線を増やさない。通常版では暗部へ逸脱する線を作らない。
- ラベル: 日本語の軸名を主表示、短い説明を補助表示。小画面では補助だけを隠し、軸名は残す。
- 反射: ポインター位置に追従するごく薄い放射光は使用可。操作不能なほど強く動かさない。
- 走査: 15–20秒の低速な一方向スイープを一つだけ使用可。`prefers-reduced-motion` では停止する。

分析データが存在する画面では、装飾用の固定星図を実データのプロットへ置き換える。データがない場合は、空状態であることを明示し、観測開始の操作へ導く。

## 6. アイコンと図形

- レティクル、目盛り、星点、ノブはCSSまたは小さなSVGで描く。線幅と光学サイズを統一する。
- 絵文字をUIアイコンとして使わない。
- ラスター画像へテキスト、ボタン、入力、グラフを焼き込まない。
- 画像生成は、新しいブランドイラストや質感そのものが必要な場合のみ検討する。確立済みの観測装置UIを再現するためだけには使わない。
