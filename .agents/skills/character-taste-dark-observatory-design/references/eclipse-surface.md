# Eclipseトップ画面の規約

## 1. 画面の仕事

トップ画面は、新規ユーザーを作成するか既存記録へログインするかを選ぶ入口である。dark版でも機能は増やさない。

- トップの主要操作は「新規ユーザ作成」「ログイン」の二つだけ。
- ユーザー一覧を置かない。
- ログインモーダルはユーザー名とログインキーを持つ。
- 新規作成モーダルはユーザー名と新しいログインキーを持つ。
- 世界観の文言より、ラベル、送信結果、エラーの分かりやすさを優先する。
- 通常版と同じ操作順、フォーム項目、入力属性、モーダル挙動を保ち、美術テーマだけで機能差を作らない。

## 2. 構図

```text
┌─────────────────────────────────────────────────────────────┐
│ 欠けた照準印  キャラ嗜好ラボ        黒蝕式観測機    準備完了 │
├─────────────────┬───────────────────────────────────────────┤
│                 │                                           │
│ 黒蝕を観測する   │          偏心した巨大な日食               │
│                 │        欠損目盛り／異常軌道／傷            │
│ 主見出し         │                                           │
│ 説明             │                                           │
│ [新規] [ログイン]│                                           │
├─────────────────┴───────────────────────────────────────────┤
│ ログインキーによる保護                                     │
└─────────────────────────────────────────────────────────────┘
```

- 通常版の筐体構造を保ち、左を整備された操作盤、右を侵食された光学室に分ける。
- 汚れは右の光学室と外枠へ集中させ、左の本文・ボタン周辺は静かにする。
- 日食は画面高の60–78%を使い、最も大きな形にする。モバイルでも小さなカードにしない。

## 3. 日食の意味と造形

物語の一文は「光が欠けるほど、隠れていた嗜好の影が満ちていく」とする。

- **外周:** 鈍い銀と青鋼が酸化した目盛り。右上または左下の15–30度分だけ摩耗・欠損させる。
- **光輪:** 酸化銀と冷たい青灰を主体にした細いCorona。一点だけ青鋼の局所光で接触を示す。
- **遮光円:** 光学中心から2–5%ずらす。完全な黒ではなく、ごく薄い青鈍の反射を残す。
- **照準:** 正常な十字線の片側を途中で切り、異常軌道がその先へ続く。
- **軸:** 表情、信念、関係性、葛藤は明瞭に残す。dark演出で文言を置換しない。
- **異常軌道:** 四軸の関係を一部通過し、円外の暗部へ消える一本の銀青色SVG path。派手に発光させない。

## 4. コピー

推奨例。既存文言やユーザー指定があればそれを優先する。

- 補助ラベル: `黒蝕を観測する`
- 見出し: `光が欠けるほど、嗜好は満ちる。`
- 説明: `惹かれた表情、譲れない信念、忘れられない関係性。日食の暗がりにだけ現れる軌道から、まだ言葉にならない「好き」の輪郭を観測します。`
- 保護情報: `分析内容と生成履歴はログインキーで保護されます`
- ヘッダー補助: `黒蝕式嗜好観測機`、状態は事実としての`観測準備完了`

「悪に染まる」「汚染されたユーザー」「危険な嗜好」など、ユーザーを評価する文言は使わない。

## 5. コンポーネント

- Primaryボタンは深い青鋼の面に銀白文字。鮮やかなシアンやグローを避ける。
- Secondaryボタンは青黒い鉄面、鈍い銀の境界。Hoverで縁が擦れて現れる程度の変化にする。
- 入力は均一な青黒い面と読みやすい銀白文字。テクスチャを敷かない。
- モーダル外枠には摩耗を入れてよいが、入力、ラベル、閉じる、エラーへ入れない。
- フォーカスは銀白の主輪と青鋼の外輪を併用して明確にする。

## 6. レスポンシブ

- 720px以下では、ヘッダー、操作盤、日食、フッターの順で一列化する。
- 操作盤のコピーと二つのボタンを日食より先に見せる。
- 430px以下ではボタンを一列に積む。
- 日食は幅102–110vwまで許容し、片側を意図的に画面外へ切る。文書全体の横スクロールは発生させない。
- 補助英字、細かな角度、軸の説明から省略し、軸名と日食の意味は残す。

## 7. 完了判定

- 最初の印象が「高級な黒金」ではなく「動作しているが何かに侵食された観測器」になっている。
- 日食、欠損、摩耗、異常軌道が同じ物語を語り、無関係な装飾がない。
- 通常版の赤・黄の発光と明確に対照をなし、鈍色・酸化銀・青鋼のcold darkとして見える。
- 本文、二つの操作、モーダル、フォーカスは通常版と同等以上に明瞭。
- 320px幅で横スクロールがなく、主要操作が画面外へ失われない。
- reduced-motionで止めてもdark版の意図が伝わる。
