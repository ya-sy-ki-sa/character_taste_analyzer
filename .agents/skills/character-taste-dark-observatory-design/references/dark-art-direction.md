# 黒蝕式観測装置のアートディレクション

## 1. 物語

dark版の核は「善が欠け、悪が満ちる日食」である。ただし、画面へ悪魔や血を直接描くのではなく、正常な観測装置に起きた次の変化で表現する。

- 光学中心と黒円の中心がわずかにずれている。
- 円周の目盛りが一部だけ欠け、異なる材質で補修されている。
- 光が当たった箇所だけ、酸化、引っかき傷、乾いた汚れが見える。
- 四つの嗜好軸は正常だが、それらを結ぶ一本の軌道だけが閉じない。
- 装置はまだ動作し、操作面は整備されている。完全な廃墟にはしない。

キーワードは、封印、黒蝕、侵食、偏心、古い測定器、煤、鈍色、酸化銀、青鋼、青黒、静かな圧力。避ける語彙は、赤・黄の暖色発光、金色の豪華さ、派手な魔法、ネオン、サイバーパンク、ゴア、ハロウィーン、安価なホラー演出。

## 2. dark専用トークン

通常版と同じ`--ctl-*`役割トークンを次で上書きする。これによりコンポーネントの機能CSSを分岐させず、装置の状態だけを変える。dark版固有の腐食・痕跡だけを`--dark-*`で追加する。本文のコントラストを確保するため、背景だけを黒くして文字を暗くしない。

```css
[data-observatory-theme="eclipse"] {
  color-scheme: dark;
  --ctl-void: #020509;           /* 光を吸う青黒の最背面 */
  --ctl-chassis: #0b1115;        /* 煤けた青鈍の筐体 */
  --ctl-panel: #141b20;          /* 鈍色の操作盤 */
  --ctl-lens: #010609;           /* レンズ内の冷たい虚空 */
  --ctl-text-primary: #e3eaec;   /* 主要文字。暗部へ沈まない銀白 */
  --ctl-text-muted: #a9b7bd;     /* 補助文字。十分に明るい青灰 */
  --ctl-control-edge: #5e6b72;   /* 入力枠・非活性部 */
  --ctl-structure: #8e9ba1;      /* 摩耗した目盛りと露出金属 */
  --ctl-action: #315a70;         /* Primary面。銀白文字と6.1:1 */
  --ctl-signal: #416f87;         /* 現在位置・選択・異常線 */
  --ctl-local-light: #91aebe;    /* 傷を暴く冷たい局所光 */
  --ctl-line: rgb(227 234 236 / 15%);
  --ctl-metal-line: rgb(142 155 161 / 40%);
  --ctl-shadow: rgb(0 0 0 / 78%);
  --dark-oxidized-blue: #284653; /* 酸化皮膜。局所使用 */
  --dark-deep-blue: #263f4d;     /* 説明されない冷たい痕跡 */
}
```

- `text-primary` と `text-muted` は正常な情報層。ノイズ、mix-blend-mode、opacity低下をかけない。
- `structure` は露出した鈍銀、`oxidized-blue` は時間、`deep-blue` は説明されない痕跡、`action`は主要操作、`signal`は現在位置と異常を表す。
- 通常版の赤・黄と競合する暖色を主役にしない。Primary、日食の接触点、異常線も青鋼から銀白の範囲で統一する。
- 青を暗くしすぎて文字へ使わない。本文は銀白、補助文は明るい青灰、低明度の青は面・境界・痕跡へ限定する。
- 主要文字、補助文字、ボタン文字はWCAG AAの4.5:1以上を確保する。装飾線と汚れはこの可読層より低い明度に留める。

## 3. 摩耗をCSSで作る

画像テクスチャへ依存せず、疑似要素を重ねる。ノイズは面ごとに原因を変える。

```css
.worn-chassis::before {
  background:
    radial-gradient(ellipse at 8% 78%, rgb(40 70 83 / 24%), transparent 19%),
    radial-gradient(ellipse at 72% 0%, rgb(38 63 77 / 14%), transparent 25%),
    repeating-linear-gradient(111deg, transparent 0 12px, rgb(227 234 236 / 1.4%) 13px, transparent 14px);
}

.corroded-ring {
  background:
    repeating-conic-gradient(from 3deg,
      var(--ctl-structure) 0 .28deg,
      transparent .28deg 2.7deg,
      var(--dark-oxidized-blue) 2.7deg 2.86deg,
      transparent 2.86deg 4.1deg),
    #10171b;
}
```

- 傷は細く、方向を揃えすぎない。文字の背後には置かない。
- 錆は下端、継ぎ目、ボルト、熱源の近くへ集中させる。
- 指が触れるボタン面は汚すより、縁の塗装が擦れて金属が露出した表現にする。
- 全面に均一なgrainをかけない。uniform grungeは物語ではなくフィルターに見える。

## 4. 間違った幾何学

視認直後ではなく、数秒後に違和感へ気づく強さにする。

- 外周リングと黒円を2–5%だけ偏心させる。
- 円を完全に歪めず、片側の曲率だけをわずかに変える。
- 目盛りを全て壊さず、日食の接触点付近だけ欠損させる。
- SVGの異常軌道は四軸の一点を通りながら閉じず、暗部へ消える。
- 重複する円、無限の目、触手など、意味が強すぎるホラー記号を加えない。

## 5. 光と動き

- 全体を均等に明るくせず、操作盤は拡散光、スコープは細い環光、傷は斜めの局所光で見せる。
- Coronaは白い美しい輪にせず、くすんだ酸化銀を主体にし、一点だけ冷たい青鋼へ変色させる。広い青グローや鮮やかなシアンにはしない。
- 15–24秒の遅い走査または呼吸を一つだけ使う。急な点滅、画面全体のglitch、常時揺れる文字は禁止する。
- ポインター反射は腐食を浮かせるために使い、追従量を小さくする。
- `prefers-reduced-motion: reduce` では全て停止しても異常が読み取れる静止構成にする。

## 6. 判読性と倫理

- 文字、フォーム、ボタン、フォーカス、エラーは通常版と同等以上に読むことができる。
- 汚れや欠損を、disabled、validation error、loadingと誤認させない。
- ユーザーの嗜好やキャラクターを悪・病気・汚染と断定しない。黒蝕は装置と画面の演出である。
- 不穏さのために個人情報、警告、エラーを偽造しない。
